# Laxmi Tiles — End-to-End Data Analysis

An end-to-end data analysis project covering the complete journey from **data warehousing to business reporting**.

**Workflow:**  
Data Warehousing → ETL → Data Cleaning → EDA → SQL Analysis → Dashboard → Reports

## Project Structure

- **Level 1** — Data warehouse and database setup
- **Level 2** — ETL, data cleaning and transformation
- **Level 3** — EDA and SQL-based business analysis
- **Dashboard** — Final data visualization and dashboard
- **Reports** — Final analysis and business findings

## Tools

SQL Server • SSMS • SQL • Python • Excel • Power BI/Tableau

## Objective

To transform raw business data into clean, structured and meaningful insights for understanding sales performance and supporting business decisions.
